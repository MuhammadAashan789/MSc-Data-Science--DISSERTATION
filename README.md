**Predicting Stock Market Volatility Using Machine Learning**

This project focuses on predicting S&P 500 market volatility using a combination of machine learning models and macroeconomic indicators. It integrates financial time-series data with economic data to improve prediction performance.


**Project Overview**

The notebook demonstrates a full my data science project pipeline:

1. Data collection (financial + macroeconomic)
2. Data preprocessing & feature engineering
3. Volatility calculation.
4. Model training using:
   4.1 q . XGBoost
   4.2 LSTM (Deep Learning)
   4.3 GARCH (Statistical model)
5. Model evaluation & comparison
6. Visualization of results


**Why I use these models: **

GARCH → Traditional volatility modeling
XGBoost → Machine learning regression
LSTM → Deep learning for time-series forecasting

**Data Sources**
1. S&P 500 Data → via yfinance
2. Macroeconomic Data → via FRED API
